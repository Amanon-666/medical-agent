# 任务二医学标注集使用说明

## 作用

任务二使用公开医学信息抽取标注数据作为质量依据和评测输入。标注集不随项目主包和数据库包分发，运行评测时通过命令行参数传入本地文件。

## 两类数据的分工

| 数据 | 标注内容 | 项目用途 |
| --- | --- | --- |
| CMeEE | 医学实体及其文本边界、类型 | 实体识别评测、症状质检词表和实体边界校验 |
| CMeIE | 医学实体之间的关系 | 关系类型映射、关系抽取校验和关系评测 |

CMeEE、CMeIE 是医学信息抽取标注基准，不是临床诊疗指南，也不替代医疗机构的诊疗规范。

## 数据来源和许可

项目按 CBLUE 官方仓库的数据格式和评测定义使用 CMeEE、CMeIE。使用前应从数据提供方获取对应版本，并遵守数据集仓库的许可证、引用和再分发要求。

项目不会把外部标注文件复制进 Git，也不会把未取得授权的标注文件打包到正式提交包。

## 本地准备

建议把外部文件放在项目之外，例如：

~~~text
external-data/
├── CMeEE-V2_dev.json
└── CMeIE_dev.jsonl
~~~

文件名可以不同，评测命令中传入实际路径即可。正式评测前建议记录文件版本和 SHA-256，确保不同运行使用的是同一批输入。

## 正式评测入口

从项目根目录执行：

~~~powershell
$env:PYTHONPATH=(Get-Location).Path
$env:PYTHONIOENCODING='utf-8'

python tests\eval_offline.py `
  --cmeee <path-to-CMeEE-V2_dev.json> `
  --cmeie <path-to-CMeIE_dev.jsonl> `
  --kg-db data\task2_medical_kg.db `
  --split holdout `
  --backend offline `
  --offline-view gated `
  --no-display `
  --output tmp\task2_formal_eval\report.json `
  --charts tmp\task2_formal_eval\charts
~~~

完整命令见 [任务二评测入口](../evaluation/task2/README.md) 和 [统一评测命令](../tests/EVAL_COMMANDS.md)。

## 指标口径

- 实体识别按实体文本、起止位置和类型严格匹配。
- 关系抽取按主语、关系类型和宾语严格匹配。
- 正式质量口径使用固定留出集计算 Precision、Recall 和 F1。
- 无标签测试集不能计算 F1。
- hybrid 和 llm 后端需要外部模型服务；模型失败时必须保留降级记录，不能把离线结果冒充模型成绩。

## 数据边界

标注集用于评测实体和关系抽取，不等于项目的全部医学知识。知识图谱中的正式事实还需要经过来源登记、实体边界、关系端点、否定范围、去重和可靠性校验。
