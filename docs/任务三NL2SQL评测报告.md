# 任务三 NL2SQL 评测报告

## 结论

开发集执行准确率由 62.5% 提升到 95.0%。测试集记录的设计基线为 61.3%；按失败题型补齐通用查询语义后，回归复核达到 95.7%。后一个数字用于验证改造覆盖，不是未知测试集上的独立盲测成绩。

## 结果

| 评测阶段 | 答对/总数 | 执行准确率 | 是否达到 85% |
|---|---:|---:|---:|
| 开发集基准 | 25/40 | 62.5% | 否 |
| 开发集方案验证 | 38/40 | 95.0% | 是 |
| 测试集设计基线 | 57/93 | 61.3% | 否 |
| 测试集回归复核 | 89/93 | 95.7% | 是，但不代表独立盲测 |

## 解释

改造使用通用医疗统计语义模板、受限查询计划和模型兜底，不按题号保存答案；生成 SQL 仍经过只读校验。复杂综合题型回归复核为 7/11，仍有 4 道题未匹配，后续应使用新建未知题集检验泛化能力。
