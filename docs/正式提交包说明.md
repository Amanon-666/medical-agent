# MediFlow 正式提交包说明

## 提交内容

| 文件 | 内容 |
| --- | --- |
| `MediFlow.zip` | 项目代码、部署脚本、评测题集、说明文档和技术报告 PDF |
| `MediFlow-数据包.zip` | 图谱库、分析库、数据处理规则库和基准评测库 |

## 使用顺序

1. 解压 `MediFlow.zip`，进入项目目录。
2. 解压 `MediFlow-数据包.zip`。
3. 按 `docs/数据资产包说明.md` 安装数据库和规则库。
4. 按 `DEPLOY.md` 配置环境并启动服务。
5. 从 `evaluation/README.md` 选择相应评测入口。

## 主包内容

- 三类智能体服务和 MCP 工具；
- DataMate 算子及注册脚本；
- Nexent Agent 发布、知识库创建和绑定脚本；
- 三类能力的评测入口、测试集和中文结果；
- NL2SQL 题集、标准结果和图表生成脚本；
- 技术报告 PDF；
- 部署、配置、数据和使用说明。

主包不包含数据库、缓存、备份、日志、模型密钥和本机运行配置。数据库及规则库统一放在数据包中。

## 提交包检查项

- 主包和数据包名称、目录结构与说明一致；
- 主包内没有 `*.db`、缓存、备份和真实配置；
- 数据包 `MANIFEST.json` 中的大小和 SHA-256 与实际文件一致；
- NL2SQL 评测显式使用 `evaluation/task3/data/task3_analytics.db`；
- 技术报告 PDF 可以直接打开。
