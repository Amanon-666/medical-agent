# MediFlow 数据资产包说明

## 两个压缩包

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `MediFlow.zip` | 代码、部署脚本、评测题集、说明文档和技术报告 PDF | 部署、阅读和评测 |
| `MediFlow-数据包.zip` | 图谱库、分析库、数据处理规则库和基准评测库 | 运行服务和执行评测 |

数据库体积较大，因此单独放在数据包中。

## 数据包结构

```text
MediFlow-数据包/
├── README.md
└── release-data/
    ├── MANIFEST.json
    ├── runtime/
    │   ├── data/
    │   │   ├── task2_medical_kg.db
    │   │   └── task3_analytics.db
    │   └── operators/
    │       ├── llm_noise_filter/noise_kb.db
    │       └── medical_term_normalizer/term_kb.db
    └── evaluation/
        ├── task1/runs/operator_v2_latest/knowledge_base/
        └── task3/data/task3_analytics.db
```

## 文件作用

- `runtime/data/task2_medical_kg.db`：医学知识图谱库，保存实体、关系、三元组、来源和质量记录。
- `runtime/data/task3_analytics.db`：在线分析库，供统计、排序、分组和自然语言查询使用。
- `runtime/operators/...`：数据处理算子使用的噪声规则库和医学术语映射库。
- `evaluation/task1/...`：数据处理评测使用的基础规则库和学习后规则库。
- `evaluation/task3/data/task3_analytics.db`：与 133 道 NL2SQL 题及标准结果配套的基准评测库。

## 安装运行数据

在主包项目根目录执行，`$dataPackage` 指向数据包解压后的 `release-data`：

```powershell
$dataPackage = "..\MediFlow-数据包\release-data"

Copy-Item "$dataPackage\runtime\data\task2_medical_kg.db" `
  "data\task2_medical_kg.db" -Force
Copy-Item "$dataPackage\runtime\data\task3_analytics.db" `
  "data\task3_analytics.db" -Force
Copy-Item "$dataPackage\runtime\operators\llm_noise_filter\noise_kb.db" `
  "operators\llm_noise_filter\noise_kb.db" -Force
Copy-Item "$dataPackage\runtime\operators\medical_term_normalizer\term_kb.db" `
  "operators\medical_term_normalizer\term_kb.db" -Force
```

## 运行 NL2SQL 基准评测

```powershell
python evaluation\task3\run_benchmark.py `
  --split test `
  --database "$dataPackage\evaluation\task3\data\task3_analytics.db" `
  --output tmp\task3_formal_test.json
```

运行态分析库用于在线服务，基准评测库与题目标准答案对应。数据文件的大小、SHA-256 和完整性结果记录在 `MANIFEST.json` 中。
