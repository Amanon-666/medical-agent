\chapter*{摘\quad 要}
\addcontentsline{toc}{chapter}{摘要}

医疗资料同时包含自由文本、表格、JSON 嵌套对象和 PDF，处理过程需要在数据平台、智能体和领域服务之间保持数据集、运行状态与来源信息的一致。MediFlow 面向这一工程问题，将 DataMate 的数据集、算子和任务接口封装为 MCP 工具，并通过统一的数据对象连接数据处理、知识构建和分析查询。系统以 Nexent 为对话入口，提供医疗数据处理、知识图谱构建与问答、医疗数据分析三个智能体配置；自定义智能体也可以按需复用同一组工具。

数据处理智能体按文件格式选择 DataMate 算子链，完成医疗术语规范、语义噪声过滤和结构保持；PDF 先经 MinerU 提取正文，再进入文本处理链。知识图谱智能体把清洗结果解析为统一记录，执行实体关系抽取、候选分级、校验去重和双库投影；离线规则、模型抽取与级联流程使用相同的校验和入库边界。分析智能体将自然语言问题转换为查询计划，在只读限制下执行 SQL，并从同一条分析结果记录生成回答、表格、图形和导出文件。本地自动化测试共 20 项，任务一和任务二测试全部通过；在线工作台对八类业务问题进行了连续请求核验，中位响应时间为 539--824\,ms。上述结果说明，MediFlow 已形成面向医疗资料的可部署处理、知识构建和受控分析闭环。
