# 任务一算子清洗评测

这套评测在本地直接运行项目清洗算子，用固定生成的 TXT、CSV、JSON、JSONL 压力集检查噪声清除、医学术语规范、医学内容保护和文件结构保持。评测不连接 Nexent、DataMate 或网络模型，结果用于工程回归，不代表赛题官方盲测成绩。

## 运行

在项目根目录执行：

```powershell
python -m evaluation.task1.run_benchmark
python -m pytest tests\task1\test_local_benchmark.py -q
```

默认结果写入 `evaluation/task1/runs/operator_v2_latest/`。输入文件和金标准由脚本运行时生成：

- `input/`：输入文件和 `gold_manifest.json`；
- `outputs/base/`：只使用基础规则的输出；
- `outputs/learned/`：加入噪声学习规则后的输出；
- `results/`：机器可读的 JSON、CSV 指标；
- `figures/`：质量图和噪声学习对照图，提供 PNG、PDF、SVG。

可用 `--run-dir <目录>` 指定输出目录，追加 `--strict` 让质量门禁不通过时返回非零状态。

## 数据和指标

每种格式生成 20 个文件，共 80 个文件、260 条记录。数据包含固定噪声、3 类重复学习噪声和 5 类未参与学习的新表达，并标注术语、症状、否定词、医学数值、姓名和病历号等需要保护的内容。金标准独立生成，算子只接收原始输入。

评测在同一批输入上比较基础规则和加入噪声学习规则的结果。学习阶段使用 12 条独立确认样本；重复片段至少出现 3 次且不含医学信息时，才沉淀为精确规则。评测保留未参与学习的新表达，用于检查规则边界。

指标包括清洗 F1、术语准确率、字段准确率、记录准确率、医学内容保护率和结构通过率。完整结果和解释写入技术报告第七章；本目录只保留运行说明、评测程序和机器可读结果。

## 边界

该评测不评价真实医院病历、Nexent/DataMate 在线服务、网络模型效果或 PDF 解析质量。本地耗时只用于回归，不作为线上性能结论。
