# 任务一算子清洗压力评测

## 这是什么

这套评测直接执行项目当前清洗算子，用固定生成的多格式语料检查噪声移除、医学术语标准化、医学内容保护和结构保持。它不连接 DataMate 或 Nexent，也不把结果表述为赛题官方成绩。

## 怎么运行

在项目根目录执行：

```powershell
python -m evaluation.task1.run_benchmark
python -m pytest tests\task1\test_local_benchmark.py -q
```

结果写入 `evaluation/task1/runs/operator_v2_latest/`：

旧的 `runs/latest/` 为 5 文件缺陷定位基线，仅保留审计，不再用于展示。

- `input/`：80 个输入文件和独立金标准；
- `outputs/base/`：只使用基础规则的输出；
- `outputs/learned/`：加入噪声学习规则后的输出；
- `results/`：JSON、CSV 和中文报告；
- `figures/`：质量图与噪声学习前后对照图，均提供 PNG、SVG、PDF。

## 测试数据

- TXT、CSV、JSON、JSONL 各 20 个文件，共 80 个文件；
- TXT 每文件 1 条，结构化文件每文件 4 条，共 260 条记录；
- 覆盖系统提示、链接、Emoji、HTML、@通知、固定标记、3 类可学习重复表达和 5 类未参与学习的新表达；
- 覆盖糖尿病、高血压、慢性肾病、慢阻肺、高脂血症等文本，以及症状、否定、数值、姓名和病历编号保护；
- 金标准独立生成并保存，算子只接收原始输入。

## 噪声学习怎么测

学习阶段提供 12 条已确认的清洗差异。只有同一片段重复至少 3 次、属于允许的噪声类别、且不含症状、诊断、数值或用药信息时，才会沉淀为精确规则。随后在同一份评测集上比较基础规则与学习规则；评测集还保留 5 类未参与学习的新表达，避免只测试系统已经记住的内容。

学习阶段使用独立标注模拟教师确认，不发生网络模型调用；这项评测证明规则沉淀和复用机制有效，不代表大模型自身准确率。

## 指标

- 清洗 F1：综合衡量应删噪声是否删除、医学内容是否保留；
- 术语准确率：原缩写必须消失，规范词出现次数必须与金标准一致；
- 字段准确率：逐字段比较，重复替换或残留噪声都会扣分；
- 记录准确率：一条记录所有字段均正确才通过；
- 结构通过率：文件可解析、记录数和字段集合保持一致。

## 当前结果

- 80 个文件、260 条记录全部执行完成；
- 清洗 F1 97.9%，术语准确率 99.1%，字段准确率 98.4%；
- 医学内容保护率 100.0%，结构通过率 100.0%，记录准确率 91.2%；
- 噪声学习结果以最新运行报告为准，报告分别列出固定噪声、已学习噪声、未见噪声和全部噪声，不用单一提升数字掩盖未见表达的边界；
- 剩余错误主要来自未学习的新闲聊表达和未进入术语库的 `eGFR`，因此结果没有被做成全满分。

## 已知边界

- 语料为固定生成的工程压力集，不是医院真实病历或官方盲测集；
- 不评价 DataMate/Nexent 服务、网络模型效果或 PDF 解析质量；
- 本地耗时只用于回归，不作为线上性能结论。
