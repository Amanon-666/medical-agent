## 前置说明：展示口径（供你理解，不一定要放进 PPT）

任务三的自然语言查询现在统一进入一条分析链：Nexent 对话和 Web 工作台都调用同一个分析服务，使用同一个分析库、同一套只读校验和同一种结果对象。

服务内部保留两级查询策略：常见医疗句式先生成确定性查询计划，复杂条件再生成受 Schema 约束的候选计划。两级策略是同一条链中的处理阶段，不是两套对外系统。

知识库和图谱负责文本依据、来源和关系浏览；结构化统计由分析库完成。两类证据在界面中分区呈现，知识库召回质量不并入 NL2SQL 执行准确率。

## 第三页：确定性模板不是"写死答案"（半页）

### 标题
**模板抽象的是句式，不是数据**

### 排版

```
┌─────────────────────────────────────────────┐
│                                             │
│  ✗ 不是这样：                                │
│  "肺炎有哪些症状" → SELECT ... WHERE disease='肺炎' │
│  （每多一种疾病就要多写一行 SQL，这叫硬编码）     │
│                                             │
│  ✓ 而是这样：                                │
│  "XX有哪些常见症状" → 正则提取 XX → 填入模板   │
│  SELECT symptom FROM disease_symptoms        │
│  WHERE disease LIKE '%{XX}%'                 │
│  （数据库中 14,408 种疾病，同一个模板全适用）    │
│                                             │
└─────────────────────────────────────────────┘
```

### 下方：模板覆盖的句式类型

| 句式 | 例子 | 生成的 SQL 类型 |
|---|---|---|
| 疾病→症状 | "XX有哪些常见症状" | 单表 LIKE + ORDER BY |
| 疾病→药物 | "治疗XX的常用药物有哪些" | 单表 LIKE + ORDER BY |
| 疾病→科室 | "XX应该去哪个科室就诊" | DISTINCT + LIKE |
| 来源+置信度 | "在来源'...'中，置信度大于X的Y记录有多少条" | COUNT + WHERE 多条件 |
| 数量统计 | "与XX相关的症状一共有多少种" | COUNT + LIKE |
| 交集查询 | "既关联症状'...'又关联药物'...'的疾病" | JOIN + 多条件 LIKE |

**底部一句话**：
> 模板抽取的是问题中的疾病名和关系意图，再填入查询参数；它减少常见问题对模型生成 SQL 的依赖，但不等于覆盖全部 NL2SQL 题型。

### 配图建议
- 上半是 ✗/✓ 对比色块（红/绿边框）
- 下半是六行卡片式模板示例，每行一个代码高亮的 SQL 片段
- 不画架构图，文字+代码即可

## 第四页：统一分析链中的两类证据（1 页）

### 标题
**一条分析链，按用途组织两类证据**

### 核心图（替代 v1 的复杂流程图，更简洁）

```
            用户问题
               │
               ▼
    ┌──────────────────────┐
    │ 统一分析服务           │
    │ 生成并执行只读查询     │
    └──────────┬───────────┘
               │
       ┌───────┴────────┐
       ▼                ▼
    分析库结果       图谱/知识库依据

    筛选、数量       按需补充解释
       │                │
       └───────┬────────┘
               ▼
    ┌─────────────────────────┐
    │ 同一界面分区呈现          │
    │ 数据统计结果 + 证据出处    │
    └─────────────────────────┘
```

### 底部三个例子

| 问题 | 主要证据 | 返回什么 |
|---|---|---|
| "关联疾病最多的 5 种药物" | 分析库 | 排名表 + 数字 |
| "二甲双胍的作用机制是什么" | 图谱/知识库 | 文档片段 + 来源信息 |
| "糖尿病有哪些症状，各有什么特点" | 分析库 + 证据来源 | 先列数据，再补解释 |

### 底部标注
> Nexent 当前已绑定 ccf_medical_kb（122 文档）。知识库召回和引用质量另行评测，不并入 NL2SQL 执行准确率。统计结果与来源证据分区展示。

### 配图建议
- 以统一分析服务为中心，左右放置分析库和图谱/知识库证据
- 用“按需补充”标记解释类证据，不画成第二条 NL2SQL 链路
- 底部标注用小字灰色
