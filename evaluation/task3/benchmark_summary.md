# 任务三 NL2SQL 基准测试概要

## 基准定位

- **总题数**：133 题；
- **开发集**：40 题，用于方案设计与迭代；
- **预留测试集**：93 题，先建立设计基线，再进行回归复核；
- **数据库**：`task3_analytics.db`，15 张表、5 个视图；
- **构建时间**：2026-08-09；
- **构建原则**：先写 Gold SQL，在真实数据库上执行验证，再根据 SQL 编写自然语言问题；跑不通和重复题目自动剔除。

设计基线回答“方案调整前的系统能力是多少”；回归复核回答“针对已发现问题的修正覆盖了多少”。由于回归阶段使用过设计基线暴露的失败题型，回归复核不等同于独立泛化成绩。

## 评测指标

- **主指标**：Execution Accuracy，即系统 SQL 的执行结果与 Gold Result 完全一致的题目比例；
- **计算方式**：预测 SQL 执行结果等于 Gold Result，记为正确；
- **目标**：≥ 85%；
- **统一口径**：确定性模板和模型兜底最终都进入同一个只读执行器，按同一结果指标计算。
